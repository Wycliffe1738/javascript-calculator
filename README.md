# JavaScript Calculator

A simple JavaScript calculator that performs basic mathematical operations and keeps a history of successful calculations.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero protection
- Calculation history
- History display

## Technologies

- JavaScript
- Node.js
- Git
- GitHub
